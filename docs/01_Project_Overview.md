# Retail Sales Analytics

## Descripción del proyecto

### Objetivo

Desarrollar un proyecto de análisis de datos de extremo a extremo utilizando Python, SQL y Power BI, con el fin de analizar el comportamiento de las ventas de una empresa del sector retail y generar información que facilite la toma de decisiones.

### Tecnologías

- Python
- SQL
- Power BI
- Git y GitHub
- Visual Studio Code

### Flujo del proyecto

1. Obtención de los datos.
2. Limpieza y transformación de los datos.
3. Análisis exploratorio (EDA).
4. Análisis mediante SQL.
5. Desarrollo del dashboard en Power BI.
6. Presentación de conclusiones y recomendaciones.

### Resultado esperado

Al finalizar el proyecto se contará con:

- Un conjunto de datos limpio y preparado para el análisis.
- Consultas SQL orientadas al negocio.
- Un dashboard interactivo en Power BI.
- Conclusiones basadas en los datos.
- Documentación completa del proyecto.
