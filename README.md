
# 📊 Retail Sales Analytics

# 📌 Descripción

Retail Sales Analytics es un proyecto de **Análisis Exploratorio de Datos (EDA)** desarrollado en Python con el objetivo de identificar patrones de comportamiento en las ventas de una empresa del sector retail.

A través del análisis de más de **9.900 registros**, se estudian variables como ventas, ganancias, categorías de productos, regiones geográficas, segmentos de clientes y tendencias temporales para generar información que apoye la toma de decisiones basada en datos.

---

# 🎯 Objetivos

- Analizar la evolución de las ventas y ganancias.
- Identificar las categorías y productos con mejor desempeño.
- Evaluar el comportamiento comercial por región.
- Analizar la participación de cada segmento de clientes.
- Detectar oportunidades de mejora mediante el análisis de datos.

---

# 📂 Dataset

El conjunto de datos corresponde a un histórico de ventas del sector retail e incluye información sobre:

- Órdenes de venta
- Clientes
- Productos
- Categorías y subcategorías
- Regiones
- Ventas
- Descuentos
- Ganancias
- Fechas de compra

**Total de registros:** 9.994

**Total de variables:** 25

# 📈 Principales Análisis

Durante el proyecto se realizaron análisis sobre:

- Evolución de ventas por año.
- Evolución de ganancias por año.
- Comportamiento mensual de ventas.
- Comportamiento mensual de ganancias.
- Ventas por categoría.
- Ganancias por categoría.
- Top 10 subcategorías por ventas.
- Top 10 subcategorías por ganancias.
- Ventas por región.
- Ganancias por región.
- Ventas por segmento.
- Ganancias por segmento.

---

# 📊 Principales Hallazgos

- 📈 Las ventas presentan un crecimiento sostenido entre 2014 y 2017.
- 💻 Technology es la categoría con mayor rentabilidad.
- 🌎 West lidera tanto en ventas como en ganancias.
- ⚠️ La región Central vende más que South, pero obtiene una menor ganancia.
- 👥 Consumer representa el segmento con mayor volumen de ventas y rentabilidad.
